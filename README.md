# YouTube Desk Agent

This project lets a user enter a YouTube video link and receive a printable one-page desk reference with captivating visuals.

## Planned Output

- Main idea
- Five key messages
- Practical applications
- Start doing
- Stop doing
- Daily checklist
- Reflection question
- Limitations
- One-page visual summary (printable PDF)

## Project Stages

1. Accept a YouTube link
2. Retrieve the transcript
3. Analyze the transcript using AI
4. Generate practical advice
5. Create a visual one-page layout
6. Export the result as a downloadable PDF
